MobileNet Duplicate Remover

A Python image-deduplication pipeline that detects byte-for-byte duplicates and groups visually similar images using MD5 hashing, MobileNetV3-Small feature embeddings and FAISS nearest-neighbour search.

01 / Overview

Cleaner datasets. Less manual review.

Computer-vision datasets often contain repeated files and near-duplicate frames. They waste storage and review time and can affect dataset quality. This project automates an initial cleanup pass by combining exact file hashing with deep-learning-based visual feature comparison.

The script scans image files recursively, extracts features from candidate images, searches for nearby feature vectors and organizes the files into output categories while preserving their relative subfolder structure.

Important: similarity grouping is an automated aid, not a guarantee that grouped images are true duplicates. Review the output before deleting or excluding images from a training set.

02 / Capabilities

Three techniques working together

A fast exact-match stage runs first, then visual feature extraction and similarity clustering handle the remaining candidates.

#

Exact duplicate detection

MD5 hashes identify files with identical binary content. Repeats move to the duplicates folder.

◈

Visual feature extraction

A pretrained MobileNetV3-Small produces 576-dimensional vectors from RGB images resized to 224 × 224.

⌘

Similarity search with FAISS

FAISS runs L2 nearest-neighbour search. A connected-component pass groups images under the distance threshold.

▦

Batch processing

Images are processed in configurable batches to balance throughput and memory.

↗

CPU or CUDA

CUDA is selected automatically when PyTorch reports it available; otherwise the script runs on CPU.

▤

Folder structure preserved

Files move into categorized output folders while keeping their relative paths.

03 / Workflow

End-to-end processing pipeline

Exact repeats are removed before spending compute on visual similarity.

STAGE 01MD5 hashing

Recursively scan supported images, hash each file and separate exact binary duplicates.

STAGE 02MobileNetV3 embeddings

Load the pretrained model, drop its classifier, resize and normalize each image, then extract L2-normalized vectors.

STAGE 03FAISS + graph clustering

Search up to 10 neighbours, connect candidates under the threshold and find connected components with breadth-first search.

05 / Usage

Run it on your dataset

Install the dependencies, set the dataset path in the configuration section of the script and run it. The default points to a local directory, so change DATASET_DIR on another machine.

python MobileNet_duplicate_remover.py

Practical safeguards

  • Back up the dataset first, because the script moves files.
  • Start with a small folder and inspect all three output categories.
  • Check threshold behaviour on true and false matches.
  • Reduce BATCH_SIZE if GPU memory is limited.
  • Keep annotations and image paths aligned when cleaning ML datasets.
06 / Considerations

What to know before using it at scale

≈

Similarity is approximate

Feature similarity does not prove two images are duplicates. Review clusters before making dataset decisions.

⏱

Search cost grows

FAISS IndexFlatL2 is exact brute-force search, which gets expensive as the dataset grows.

📁

File movement matters

The script moves files and preserves relative paths. Verify output and any annotation files before training.
