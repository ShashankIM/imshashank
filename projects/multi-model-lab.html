Multi-Model Detection + Classification Testing Lab

A browser-based model testing lab built with Python and FastAPI. Evaluate multiple ONNX detection and classification models in one workflow, inspect annotated results and validate model behavior without a separate inference script for every model.

03 / Testing modes

Three ways to test

Pick the workflow that matches the question you want to answer about a model.

MODE 01Detection only

Run detection models and view bounding boxes, labels, scores and annotated previews.

MODE 02Classification only

Classify the whole image and return the predicted class and score.

MODE 03Detect → crop → classify

Detect objects, crop each region and run selected classifiers on the crops. Results attach to detections.

06 / Architecture

Small, modular and easy to extend

The frontend talks to a FastAPI backend. A model registry discovers assets, and the inference layer runs models through ONNX Runtime and prepares outputs for display.

Core components

  • Frontend: HTML, CSS and JavaScript browser UI.
  • API: FastAPI endpoints and request orchestration.
  • Inference: ONNX Runtime detection and classification wrappers.
  • Registry: model and label-file discovery.
  • Image processing: decoding, cropping, drawing and encoding.
  • Storage: model and label files grouped by task type.

07 / API and setup

Key endpoints and quick start

MethodEndpointPurpose
GET/Serves the main testing dashboard.
GET/uploadServes the model upload page.
GET/modelsReturns available models and their labels.
POST/predictRuns inference on uploaded images with selected models and thresholds.
POST/upload_modelValidates and stores a model file and its matching label file.
Run locally
# 1. Create and activate a virtual environment
python -m venv .venv
source .venv/bin/activate

# 2. Install dependencies
pip install fastapi uvicorn onnxruntime opencv-python pillow numpy torchvision pydantic python-multipart

# 3. Start the application
uvicorn app.main:app --host 0.0.0.0 --port 5000 --reload

Open dashboard

http://localhost:5000/

Upload models

http://localhost:5000/upload

Pair labels correctly

Keep each model and label file on the same base name, such as helmet.onnx and helmet.txt.

CPU inference is supported everywhere. For GPU execution, check that your ONNX Runtime package and CUDA versions are compatible.
