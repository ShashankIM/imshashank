01 / Overview

Prompt-driven polygon annotation

Manual polygon annotation is slow for dense or high-resolution imagery. SAM-family models generate initial masks from natural-language class prompts or a drawn bounding box, and the app turns those masks into editable polygon annotations.

⌕

Prompt-driven discovery

Enter comma-separated class prompts such as ship, airplane, shed. Prompts are parsed and duplicates removed case-insensitively.

▱

Visual guidance

Draw a rectangle around an object, assign a label and use the box as a segmentation prompt.

⬡

Polygon-first output

Binary masks become simplified contour polygons with configurable minimum-area filtering, ready for LabelMe JSON.

04 / Inference

Two inference strategies

Two variants balance speed, memory use and large-image coverage.

Speed-focused full-image mode

sam_single_shot.py

  • Sends the complete image to the model without tiling.
  • Submits the parsed text prompts together for each image.
  • Fewer passes and simpler orchestration.
  • Useful when the image fits in available RAM and VRAM.
Large images may need significant GPU memory, and small-object detail is harder to preserve.

High-resolution tiled mode

sam_tiles.py

  • Uses 1536 px tiles with 256 px overlap by default.
  • Can add a downscaled full-image context pass for large images.
  • Maps tile-local polygon coordinates back to the source image.
  • Reconciles same-label overlaps across tiles and context predictions.
Tiling improves local detail but adds inference time. Reconstruction is heuristic and needs visual QA.

05 / Architecture

Implementation and architecture

A compact Python application built around Streamlit, Ultralytics SAM APIs, OpenCV contour geometry and LabelMe-style annotation structures.

Core components

  • Streamlit: upload, controls, progress, review and downloads.
  • SAM3SemanticPredictor: text-prompt semantic segmentation.
  • Ultralytics SAM: box-guided visual segmentation.
  • OpenCV + NumPy: contours, simplification, mask overlap calculations.
  • Pillow: image decoding and translucent overlay rendering.
  • Session state: keeps each image's annotations during the session.

Polygon processing

  1. Convert each mask to a binary array.
  2. Extract external contours.
  3. Drop contours below the minimum area.
  4. Simplify contour vertices with polygon approximation.
  5. Keep contours with at least three points.
  6. For tiled inference, restore global coordinates and reconcile overlapping same-label polygons.

06 / Outputs

Outputs and annotation format

The export is inspectable and portable. The JSON references the original image filename; image pixels are not embedded.

Each file holds image metadata and a shapes list of labelled polygons.

07 / Run locally

Run it on your machine

You need a compatible Python environment and an accessible SAM checkpoint.

1. Install dependencies

python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install streamlit streamlit-drawable-canvas \
  opencv-python numpy pillow ultralytics

Install a PyTorch build that matches your CPU/GPU. SAM 3.1 predictor support depends on the Ultralytics version.

2. Place checkpoints

Paths are configurable in the app sidebar. Use checkpoints you are authorized to access and redistribute.

~/AI_annotation/
├── sam3.pt
└── models/
    └── sam3.1_multiplex.pt
3. Launch a variant
# Full-image, speed-focused workflow
streamlit run sam_single_shot.py

# Tiled high-resolution workflow
streamlit run sam_tiles.py
08 / Quality control

Quality control, limitations and FAQ

The pipeline accelerates annotation, but model output and geometry heuristics are not a substitute for review.

Review before training

  • Check false positives and missed objects.
  • Inspect boundaries on small or crowded objects.
  • Look for merged adjacent instances and duplicate polygons.
  • Confirm each polygon has the intended class label.

Known limitations

  • Full-image inference can use substantial VRAM.
  • Tiled inference adds runtime and overlap-handling complexity.
  • Contour simplification may lose fine boundary detail.
  • External contours do not encode interior holes as rings.
  • Session annotations are not persisted in a database.
  • JSON uses imageData: null, so keep source images available.
Which script should I use?

Use sam_single_shot.py when the full image fits comfortably in memory and speed matters. Use sam_tiles.py for larger images where tile-level detail and context reconstruction help.

Does the application guarantee correct polygons?

No. The model generates candidate masks. Inspect overlays and correct incorrect or incomplete polygons before treating them as training annotations.

Can I use a GPU?

Yes, when PyTorch, the checkpoint, the driver and the Ultralytics version are compatible. The device selector offers automatic, GPU 0, GPU 1 or CPU.

Can I publish the checkpoint files with the code?

Only if the model terms permit redistribution. Keep large or restricted weights out of public repositories and document the checkpoint setup instead.
