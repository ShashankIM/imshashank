01 / Overview

Make team work visible, organized and auditable.

Daily work logs, assigned tasks, employee administration and activity history live in one internal tool. A separate MCP service exposes selected operations through predefined tools instead of arbitrary database commands.

Problem it addresses

Teams need a consistent way to record daily work, assign follow-ups, review missing submissions and understand changes across users and tasks without relying on manual status updates.

Project approach

  • Role-based experiences for employees, managers and administrators.
  • Centralized user, task and audit records in SQLite.
  • Monthly database shards for work history and activity records.
  • A dedicated MCP service for selected admin and reporting workflows.
  • Docker-based services for repeatable deployment.

03 / Architecture

Two services, one shared data source.

The Flask web app and the MCP server run independently while sharing the same SQLite database directory.

Technology choices

  • Python 3.12 for application and MCP logic.
  • Flask 3+ and Flask-SocketIO for the web experience and notifications.
  • SQLite for portable, lightweight persistence.
  • MCP Python SDK for tool-based admin and reporting operations.
  • Docker Compose to build and run the services.

Architecture note

Both services should use the same mounted database directory as the single source of truth. Consider backups, file permissions and SQLite write behaviour when deploying or scaling.

05 / Security

Controlled tools, explicit boundaries.

The MCP interface exposes predefined application operations rather than unrestricted database access, and every change leaves an audit trail.

Safeguards implemented

  • Password hashing with Werkzeug.
  • Role validation for admin, manager and employee workflows.
  • No arbitrary SQL tool exposed through MCP.
  • Parameterized SQL for predefined operations.
  • Password hashes are never returned by MCP tools.
  • Mutating actions are recorded in activity/audit logs.

Before production deployment

  • Change the default admin credentials and Flask secret key.
  • Keep secrets in environment-based configuration.
  • Use HTTPS and authentication if MCP is reachable outside a trusted network.
  • Restrict exposed Docker ports and access to the database volume.
  • Back up the SQLite database directory regularly.
