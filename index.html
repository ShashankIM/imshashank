01 — AI AUTOMATION / RAG

Reusable Conversational RAG Module

A backend-ready RAG system that answers questions from a private knowledge base. LlamaIndex ingests 21 knowledge files into Qdrant using local nomic-embed-text embeddings from Ollama. Answers are generated by a local model (gemma3:1b) or the OpenAI API behind the same interface. Per-user, per-session memory resolves follow-up questions by enriching retrieval with recent turns, with no extra LLM call. Served through FastAPI with a Streamlit test UI and a health endpoint, and the backend never touches vectors, prompts or memory directly.

PythonLlamaIndexQdrantOllamaOpenAI APIFastAPIStreamlit
View project →

Result

  • One call, rag.ask(), adds RAG to any Python backend
  • 2 LLM backends, local and OpenAI, behind one interface
  • Memory isolated per user and session
  • 8 error types handled, so a failure never crashes the API
  • Every answer returns sources, scores and per-stage latency
